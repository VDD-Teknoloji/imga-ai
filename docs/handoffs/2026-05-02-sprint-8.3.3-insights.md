## Mevcut durum — yapılanlar

### Backend

- **AnalyticsService** (`services/analytics_service.py`) — 7 frozen-dataclass aggregation:
  - `sentiment_distribution` — label counts + avg_score + percentage
  - `category_distribution` — top-N kategori (1 ≤ limit ≤ 50)
  - `sentiment_by_category` — heatmap matris (top-N kategori × NEGATIF/NÖTR/POZITIF) + totals_by_*
  - `override_stats` — 5 katman placeholder (knowledge_base/critical/tier1/sla/tier2). Sprint 8.3.4'te `Review.overrides_applied` JSONB doldurulduğunda implementasyon güncellenir; response shape stabil.
  - `sentiment_timeline` — gün/hafta/ay (`func.date_trunc` + `isocalendar`)
  - `ticket_resolution_time` — avg / median / p95 + 6 bucket histogram + per-category averages
  - `sensitivity_distribution` — sentiment_score histogramı 20 bucket (-1..1) + mean/median/std_dev

  Filter helper: `_apply_review_filters` + `_apply_ticket_filters` (date range, source_types, sentiment_labels, category_ids, batch_job_id).

- **Routes** (`routes/tenant_analytics.py`) — 7 GET endpoint, hepsi RLS-bound (app session + bind_tenant), `TENANT_ADMIN/ANALYST/VIEWER` rolleri:
  - `GET /tenants/me/analytics/sentiment-distribution`
  - `GET /tenants/me/analytics/category-distribution`
  - `GET /tenants/me/analytics/sentiment-by-category`
  - `GET /tenants/me/analytics/override-stats`
  - `GET /tenants/me/analytics/sentiment-timeline`
  - `GET /tenants/me/analytics/ticket-resolution-time`
  - `GET /tenants/me/analytics/sensitivity-distribution`

  CSV-encoded querystring filtreleri (`/tickets/stats` + `/reviews` pattern'i ile aynı): `date_from`, `date_to`, `sentiment_labels`, `category_ids`, `source_types`, `batch_job_id`.

- **`main.py`** — `tenant_analytics_routes.router` include edildi. Lifespan değişmedi.

### Frontend

- **`hooks/use-analytics.ts`** — TanStack Query hook'ları, 7 endpoint için. Shared `qs()` + `commonParams()` CSV array encoder.
- **`components/charts/heatmap.tsx`** — ~200 satır custom SVG heatmap. `viewBox`-responsive (parent'a sığar, ResizeObserver yok). Renk ölçeği: `lerp()` + 4 anchor (blue/green/red/diverging). Cell click `onCellClick(row, col)` callback'i tetikler; route navigation parent'ın sorumluluğu.
- **`/insights/page.tsx`** — 5 tab: Duygu, Kategori, Çapraz Analiz, Override Katmanları, Biletler.
  - URL state: `useSearchParams` + `router.replace` ile aktif tab paylaşılabilir.
  - FilterBar: `date_from`, `date_to`, `source_types` — tüm tab'ları besler.
  - SentimentTab → Pie + Histogram + Line trend (hepsi recharts).
  - CategoryTab → vertical bar chart.
  - CrossAnalysisTab → Heatmap. Hücre click → `/reviews?primary_category=X&sentiment_labels=Y`.
  - OverridesTab → bar chart (Sprint 8.3.4'e kadar zero-state placeholder).
  - TicketsTab → resolution time histogram + per-category bars.
- **`nav-config.ts`** — Sidebar'da "İçgörüler" linki (TrendingUp icon), Raporlar ↔ Ayarlar arasında.
