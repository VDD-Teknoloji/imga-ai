### Bölüm E — Override Stats Real Query

`AnalyticsService.override_stats` 8.3.3 zero-count placeholder'ı silindi. Yeni:
- LATERAL `jsonb_array_elements(overrides_applied)` ile per-layer score listeleri
- Her layer için `trigger_count`, `trigger_percentage`, `avg_impact = avg(|score|)`, `max_impact = max(|score|)`, `direction` (boost = hep pozitif, dampen = hep negatif, mixed = ikisi de, none = hiç fire etmemiş)
- Bilinmeyen layer kodları (forward-compat) sessizce dropluyor — dashboard'u crash ettirmemek için

## Riskler

- **Migration 0014 NULL handling**: Eski rows `overrides_applied IS NULL`. Detail endpoint NULL'u `[]`'e dönüştürüyor; analytics service NULL row'ları unnest dışı bırakıyor (Postgres `jsonb_array_elements(NULL)` zero rows). UI tarafı da `overrides_applied: []` kabul ediyor.
- **Pre-existing tickets**: Bridge öncesi açılan biletlerin `review_id IS NULL`. `<LinkedReviewSection>` early-return → render etmiyor.
- **Heatmap horizontal scroll**: Touch device'larda parent card scroll'u ile çakışmaz mı? `touch-pan-x` utility iOS Safari'ye horizontal pan'ı eksplicit veriyor; vertical scroll bozulmuyor.
